# weather-report
🌦️ Weather Report Web App
This is a simple weather forecast application that allows users to get the current weather and 24-hour forecast of any city using the OpenWeatherMap API.
![Screenshot 2025-04-30 181208](https://github.com/user-attachments/assets/b5ae6831-7079-49ab-82bf-d3a7fa2b98eb)


🔧 Features:

🌍 Search for any city.
🌡️ Get current temperature, weather description, and icon.
🕒 View 24-hour weather forecast (in 3-hour intervals).
💡 Clean and responsive UI with HTML, CSS, and JavaScript.

🧰 Technologies Used:

HTML5,
CSS3,
JavaScript, 
OpenWeatherMap API.

💻 How to Run (VS Code)

Install the Live Server extension from the Extensions tab.
Right-click on index.html → Open with Live Server.
Enter a city name and get weather data.
